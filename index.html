How I work

Claude Code, every day, with a process around it

  1. Write the spec

    Each feature starts as a short proposal, design and task list.

  2. Tests first

    Claude Code writes failing tests, then the implementation that passes them.

  3. Parallel, isolated sessions

    Separate git worktrees, so several features move at once without colliding.

  4. AI review loop

    A review bot checks every pull request, and I work through its findings until it comes back clean.

  5. Try it for real

    After each deploy, I drive the actual flows on staging with browser automation and write up anything that breaks.
